## 주의
현재 UI는 **시연용**이며 sessionStorage에 남는 입력만 가진다. 이 버전을 실제 사용자에게 일기 저장 서비스로 제공하면 안 된다. 가상 날짜/예시 데이터는 실제 출시 전에 제거한다.
