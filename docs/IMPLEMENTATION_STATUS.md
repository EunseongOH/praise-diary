## 주의
현재 UI는 **시연용**이며 sessionStorage에 남는 입력만 가진다. 이 버전을 실제 사용자에게 일기 저장 서비스로 제공하면 안 된다. 가상 날짜/예시 데이터는 실제 출시 전에 제거한다.

## 환경 검증 / 릴리스 상태 (2026-11-21)
- 실행 가능한 코드 소스 및 `design-preview.html` 준비.
- `npm install`은 npm 레지스트리 DNS 불가로 실패; React 실제 실행·타입 검사 및 Vite 번들 빌드는 **미검증**.
- `node scripts-verify-syntax.mjs`: 11개 TS/TSX 구문 오류 0.
- `node scripts-contrast.mjs`: 중요 6개 semantic text 조합 4.5:1 충족.
- `node tests/logic.mjs`: 날짜 경계/중복 일기/재추첨 9개 assert 통과.
- `design-preview.html`은 Chromium에서 홈/도감/꺼내보기 탐색 동작 확인.
- GitHub 앱의 선택 저장소 접근 갱신 완료. 소스/기획/디자인 브랜치와 Draft PR #1 생성; merge 전 사용자 검토. GitHub Actions 워크플로 추가(실행 결과 미확인).
- React 앱에 실제 Toss SDK, 인증, 서버 저장, 발송 기능은 전혀 연동되지 않음.


## v0.3 — 그래픽 성장 및 타이포 위계

- 월별 SVG는 **저충실도 성장 규칙 검증용**이며 정식 입자/형태 디자인은 미착수. 아래쪽 실루엣부터 reveal되는 범위를 `src/graphics/progress.ts`에 독립 모듈로 분리했다.
- D-02 저장 성공 시 이전 날짜 수부터 새 날짜 수까지 성장 애니메이션을 추가했다. 같은 날짜 추가 일기는 높이 고정.
- SUIT Variable/폰트 스케일을 토큰화하고 타이포 규칙을 모든 주요 UI에 매핑. 브랜드 색상은 보류.
- 12월 특별 목표 수는 여전히 미정: 임시 성장 비율을 완료 판정으로 취급하지 말 것.
- `typography-growth-preview.html`은 **독립 UI 시연**이며 실제 앱 화면 또는 최종 그래픽 자산이 아니다.
