## 1. 이번 작업의 의미

사용자는 단일 줄기 나선에서 B(회전+미세 부유) 또는 C(B+은은한 글자 반짝임)를 선호하지만, **여섯 갈래 눈꽃 전체가 어떤 모습일지** 확인하고 싶어 합니다. 이번 결과물을 보고 ChatGPT와 사용자가 미적 채택을 결정할 예정입니다.

**반드시 독립 개발 전용** `/__dev/full-snowflake-study`를 구현하세요. **실서비스의 `GraphicArtwork`, 홈, 도감, 일기 작성/상세는 변경하지 마세요.**

## 2. 개발 순서

1. **정지 눈꽃**: 육각 방사 큰 줄기 6개(60° 간격), 큰 줄기마다 좌우 가지 3쌍의 실루엣을 실제 가상 일기의 글자 나선으로 구성하고 0/1/5/8/15일 아래→위 성장 상태를 먼저 캡처하세요. 15일 기준 정지 화면에서 눈꽃으로 인식되지 않으면 결함을 기록하고, 눈꽃 선화·가짜 글자/별로 임의로 채우지 마세요.
2. **다중 일기 분배**: 한 줄기에 여러 일기가 축·구간별로 들어가야 합니다. 가상 fixture는 19번 명세 부록 A의 `demo-01~15`와 `extra-1/2`만 사용. 원문 순서/일기 ID 안정성을 지키고, **같은 원문을 여섯 갈래에 복사하지 마세요.** 각 날의 새 일기는 새로운 완전 글자가 보여야 하며, 같은 날짜 추가 시 높이가 늘면 안 됩니다.
3. **2.5D 모션 비교**: 축의 세계 XY 방향은 고정하고 **각 줄기·가지에 감긴 글자 나선만 자기 축 중심으로 회전**하도록 구현. 글자가 실제 앞/뒤 위치와 가림으로 보이거나 숨게 하고 미세 부유는 기존 Gate 2A-M B와 동일 원리. 아래 시안을 같은 fixture/geometry/time/카메라/기본 색으로 비교하세요.
   - **B**: 회전 + 미세 부유
   - **C0**: B + 기존 +10% 밝기 shimmer
   - **C1 [검토용 대안]**: B + 눈에 좀 더 구별되지만 여전히 절제된 shimmer(선택된 앞면 글자들이 조금 어두워졌다가 기준 밝기로 돌아옴). 구체 명도 변화와 대비를 기록하세요.
4. **고유 시간과 정밀 비교**: B/C0/C1은 반짝임 외 구조·위치·글자 수/회전 시간까지 동일해야 해요. 20초/회전 기본, 24초 비교 가능. 별 입자·글로우·가짜 뒷면 글자 복제·문장 생성 금지. 정지각과 `prefers-reduced-motion`을 지원하세요.
5. **기능·성능 검증**: Playwright Test로 성장, 같은 날 추가/삭제, 글자 일부 절단 없음, 글자 순서와 ID 안정성, 0/45/90/135/180도, 1×/2×/3.2× 독해, reduced motion 검증. CPU1×/4× Chromium에서 **단일 B/C0/C1 각각**의 FPS/p95/그린 글자 수/Canvas 호출 수를 동일 조건으로 10초×3회 측정. 세 작품을 동시에 렌더한 갤러리의 FPS를 서비스 성능으로 착각하지 마세요. 실제 앱인토스 WebView는 미검증으로 보고하세요.
