사용자가 직접 확정한 사항:

- 대표 나선은 **큰 줄기/읽기 좋은 핵심 축**, 반복 나선은 **가지·외곽·성긴 구간**에 주로 사용.
- echo 양은 고정 횟수가 아니라 **형태가 얼마나 부족한지**를 기준으로 자동 조절.
- 대표 원문의 글자 슬롯은 미래 높이까지 미리 예약하고 **고유 작성일 수가 늘면서 아래→위로 순차 공개**.

## 1. 개발 목표

신규 개발 전용 경로 **/__dev/adaptive-snowflake-study**에서 6갈래 눈꽃 전체를 렌더하세요. 실서비스는 변경하지 마세요.

**G0 (기존 Gate 2B)**: 현재 15일 기본 일기로는 눈꽃이 빈약한 비교 기준. 이전 엔진·산출물을 수정하지 말고 새 비교 페이지에서 참조/재사용하세요.

**G1 (대표 나선만)**: 구절 추출, 원문 순서/출처, 안정 ledger, 미래 글자 슬롯 예약을 검증. echo 없음.

**G2 (대표+echo)**: 원문 일부 구절을 반복 나선으로 활용해 15일 기본/짧은/초단문에서도 1×와 160px에서 눈꽃다운 밀도가 나타나는지 비교하는 시안. 새 일기나 날짜 변화에 맞춰 echo만 위치를 양보하거나 조정 가능.

중요: G0/G1/G2는 글자 수가 달라질 수 있으니 FPS/이미지 비교 시 반드시 **실제 그린 글자 수와 anchor/echo 수**를 함께 표시하세요.

## 2. 작업 단계

**2C-0: 데이터**
- 원문 grapheme offset과 어절·구두점 경계에 기반한 **자연스러운 구절 분할 v1** 구현.
- 개발 중 AI 요약/감정 분석/임의 칭찬 문구 생성 금지. 원문 없는 글자·문장부호 합성 금지.
- 원문 2~3글자, 6~12글자, 긴 글, 영어/숫자/이모지 모두 테스트.
- 각 echo에 entryId, sourceStart/end, copyIndex를 남겨 수정·삭제 및 반복 출처를 추적.

**2C-1: 대표 나선+안정 ledger**
- 일기별 기본 대표 나선 1개. 길고 연결된 기록은 복수 조각 실험 가능하되 근거 보고.
- 대표 슬롯과 초기 위상을 고정. 미래 성장 영역에 배정된 글자는 그 높이가 열릴 때 그 자리에 등장하며 그 전엔 미표시.
- 1일 1/15 성장 높이를 몰래 늘리지 말고 아래쪽 영역에 작은 눈꽃 씨앗이 되도록 표현. 정면 1자만 보이는 기존 문제 개선을 검수.
- 새 날짜가 생기면 반드시 **고유 entryDate 수**를 기준으로 높이가 증가. 동일 날짜 추가에는 높이 변화 없음.
- 기존 anchor의 좌표를 새 기록 때문에 재배치하지 마세요.

**2C-2: 밀도 적응형 echo**
- 자연스러운 구절 일부를 반복 사용. 대표 원문을 여섯 줄기로 도장 찍듯 그대로 복제하지 않음.
- 가지·외곽·부족한 영역 먼저 보강하고 중심 과밀, 같은 표현의 인접 반복, 실제 glyph 충돌을 제한.
- 각 상태의 빈 공간·축 균형·160px 실루엣을 참고해 **필요한 만큼 반복**, 정해진 n회 하드코딩 금지.
- 현재 열린 영역에서 새 일기 대표 나선과 충돌하면 **echo가 우선 양보**. 미리 배정된 미래 anchor를 침범하지 않음.
- 과밀로 추가 일기를 보여줄 수 없는 경우 보장했다고 속이지 말고 실제 제한/실패 출력.

**2C-3: 기존 모션 복원**
- 먼저 G0/G1/G2 정지 이미지로 짧은 글의 형태를 비교한 다음 G2에 **B/C0/C1을 동일한 geometry와 시간축으로** 적용.
- 실제 앞뒤 가림·축별 회전·글자들의 상관 미세 부유 유지.
- C0와 C1은 서로 다른 shimmer 조건이지만 위치, 원문, 가림, 축, 시간, 색 기본값은 동일. 별·점·네온·글로우 금지.
- 움직임 줄이기에서 세 효과 모두 반복 정지. 확대 시 독해를 완전히 잃지 않아야 함.

**2C-4: 테스트·성능**
- 0/1/3/5/8/15일, 동일 날짜 +2, 수정/삭제, 지난날 기록 추가, 글자 원문 출처, 안정 슬롯, future reveal, 반쪽 글자/상단 누출, 160px 눈꽃 크기 검사.
- 375×812 / DPR1·2 / CPU1×·4× / 10초×3회. G0/G2에 동일 fixture 사용하고 B/C0/C1은 **단일 작품**을 측정. FPS·p95·drawImage/glyph/echo 수 기록. CPU4× 불안정성·실기기 미검증 명시.
- 짧은 글에서 눈꽃이 안 보이거나 DPR2 목표가 미달이면 미달이라고 기록. 시각 완성도는 테스트 PASS만으로 단정하지 마세요.
