# 상징물별 타이포그래픽 아트·모션 정책 — v0.4

2026-11-21 사용자가 확정한 방향: **각 그래픽 상징물의 형태에 맞춰 글자를 배치하며, 움직임도 해당 구조에 따르게 설계**. 눈꽃 줄기와 갈래 가지는 각각의 방향과 회전축을 갖는다. 무작위 진동이나 모든 글자의 동기화된 흔들림 금지. 시각적인 완성도를 구현 성공과 별개로 검증한다.

- 모든 그래픽은 날짜마다 **아래에서 위로** 차오른다. 같은 날짜 추가 일기는 기존 성장 높이 안에 글자가 추가된다.
- 눈꽃: 여섯 줄기와 각 줄기의 세 쌍 가지, 글자의 방향은 각 줄기/가지의 탄젠트에 맞춰 배치. 줄기·가지는 자기 뿌리를 축으로 느리게 각기 미세 회전.
- 붉은 양과 해: 양털 곡선/머리·귀/다리/해의 방사형 구조에 따라 다른 동작을 설계하며, 지금은 원화 및 코드 미구현.
- 화면 전체 무경계 아트 캔버스 유지. 과장된 색·반짝이·글로우는 금지. 기존 색상과 SUIT 폰트는 후보.
- 목표 12월 일수는 출시일 확정 후 결정.
- 접근성: 2D 정지 상태만으로 정보 유지, OS와 앱의 움직임 줄이기 반영, 시각적 효과가 기록 저장 결과를 대신해서는 안 됨.
- 테스트: 썸네일 인지성, 1일/절반/완성 이미지, 같은 날짜 추가, 글자 중첩, 오래 봐도 피로하지 않은 움직임, 저사양 배터리.

**미완성:** entry ID 기반의 안정적인 글자 할당, 후반 과밀도의 2차 레이어, 일기 삭제 시 해당 입자의 정확한 제거, 양과 해의 테마별 경로·모션, 실제 디바이스 아트 검수. 미완성 기능을 완료되었다고 표현하지 않는다.
