## 이번 v1.6 변경 사항 [사용자 확정]

- 2026년 12월에는 **출시일에 따라 특별 목표** 제공; 구체적 일수는 출시일 확정 후 결정.
- 기존 기본 03:00 경계를 폐기하고 **00:00 자정 기본 + 이용자 설정 변경** 도입.
- 작성 날짜는 D-01 상단에 항상 명확히 표시하고, 날짜 경계·변경 상황에서 토스트/짧은 안내 병행.
- 작성 중 날짜 경계가 지나도 선택 날짜·입력 유지·유예 저장. 구체적 유예 종료 조건은 미확정.
- 오늘·어제만 쓸 수 있으므로 **미래 월 일기 작성 플로우는 불필요**. 도감의 미래 월 잠금·아이디어 제안은 유지.
- 홈에서 **모든 일기 목록 L-03 직접 접근**, 꺼내보기 10개 잠금과 완전히 독립. 길게 누르기는 선택적인 보조 수단으로만 검토.
- 원문 조회·수정·삭제 경로는 기록 잠금 여부와 무관하며, 본인 인증 및 서버 권한 확인 필요.

## 유지 관리

새로운 결정을 받으면 **해당 화면 문서·누적 PRD·CSV·IA·변경 이력**을 함께 수정한다.
사용자에게 필요 없는 내부 분류/상태코드는 UI에 노출하지 않는다. 이전 ZIP은 변경 기록으로 보관하고 최신 ZIP과 마스터 페이지를 개발 기준으로 이용한다.
