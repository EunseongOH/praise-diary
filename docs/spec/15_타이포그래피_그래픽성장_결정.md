# 칭찬일기 v1.8 · 타이포그래피·그래픽 성장 명세 (2026-11-21)

## 1. 사용자 확인 사항

- **색상은 아직 미확정**. 현재 어두운 화면 위 부드러운 파스텔 조합은 AI스러운 느낌이 있으므로, 임시 시안의 톤을 고집하지 않는다. 이번 단계에서 색상을 최종화하지 않는다.
- **그래픽 아트 퀄리티는 고도화가 필요**. 기존 SVG는 일기일 수와 형상 성장·레이아웃 연결을 테스트한 기초 구현이다. 완성형 에셋/입자 엔진/3D 렌더가 아니다.
- **새로운 기록 날짜가 쌓일수록 아래에서 위로 채워지는 형상**을 핵심 동작으로 확정. 같은 날짜 추가 일기는 높이 변화 없이 기존 영역에 글자 추가. 일기 삭제시 날짜가 없어지면 높이 감소.
- **폰트 및 타이포 위계 설계 필요**: 제목, 본문, 날짜·보조 정보, 입력 폼, 버튼 등 반복 역할의 토큰화.

## 2. 구현 기준(이번 변경)

- `src/graphics/progress.ts` 는 SVG 캔버스 높이 340px가 아니라 **실제 테마 도형의 상하 범위**를 기준으로 clip 높이를 계산. 1일 작성 즉시 하단 일부가 표시되고, 날짜 수 증가에 따라 위쪽으로 올라간다.
- `src/graphics/GraphicArtwork.tsx`에서는 다 채워진 외곽 윤곽(ghost)을 제거하고 미도달 부위를 비워 둔다.
- D-02에서 기록한 날짜 수가 증가하면 이전 높이부터 새로운 높이까지 1.1초 동안 노출되는 단순 모션을 추가했다. 접근성 설정 또는 작은 그래픽에서는 모션을 줄인다.
- 2026-12 별도 목표가 미정이므로 **완성 판정은 계속 보류**하고, SVG 시연 계산의 임시 상한과 실제 완성 정책을 혼동하지 않는다.
- 실제 글자 질감과 레이아웃은 정식 작업에서 재설계. `graphic-growth.md`에 고도화 과제를 남겨 둔다.

## 3. 타입 시스템(제안, 비교용 1차 구현)

- 기본 후보 `SUIT Variable` (OFL-1.1), 비교 후보 `Pretendard Variable`. 한국어 화면에서 하나를 선택하고, 이유 없이 제목에 영문 세리프나 다른 폰트를 섞지 않는다.
- 타이포 토큰 (CSS): 홈 Hero 28~32/700, 화면 제목 26/700, 섹션 18/600, 선택 일기 제목 20/600, 본문·일기 내용 16/400, 버튼 16/600, 설명 14/400~500, 날짜/보조 13/400~500.
- 본문 행간 1.65, 일기 원문 1.8, 제목 행간 1.3. 한국어 기본 자간 0, 제목은 -0.025em까지 제한. 대형 타이틀의 과도한 굵기(800, 900) 지양.
- 상세 명세: `design-system/typography.md` 및 `src/styles/tokens.css`.

## 4. 그래픽 실제 제작 체크리스트(미착수)

- 테마별 곡선·점 배치, 글자 형태 다양성/질감, 중첩 제어, 색상과 깊이감 디자인.
- 사용자 일기 텍스트 파티클 안정화(개별 엔트리 seed/정렬/이전 배치 보존).
- 첫 기록·같은 날짜 추가·목표 달성·수정·삭제별 전용 모션.
- 모바일 GPU/성능·배터리·저사양 폴백 테스트, `prefers-reduced-motion` 지원.
- 과거 그래픽의 재현성 및 사용자 원문 보호.

## 5. 검증 및 보류

- 문법/날짜·그래픽 성장/대비 검사 통과(수동+Node 테스트). 실제 종속성·브라우저 타입 검사와 앱인토스 실기기 테스트는 GitHub CI/이후 QA에서 확인.
- **보류:** 브랜드 팔레트, 최종 폰트 선정, 눈꽃/붉은 양 그래픽 고해상도 형태, 12월 목표 숫자, 그래픽 제작 기술 스택.
