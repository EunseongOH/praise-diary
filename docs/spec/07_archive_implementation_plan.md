## IA / 화면
기존 AppBar '내가 남긴 칭찬' → 검색(상시 표시, 자동 focus 없음) → 기간 및 마음 필터(줄바꿈) → 조건 적용 시 결과 요약/필터 초기화 → 월 섹션+기존 DiaryRow → 이전 기록 더 보기. 일반 목록에는 총 수/진행률 강제 노출하지 않음. 전체 기간에서 기록 있는 월만 헤더, 월 최신순. 특정 연/월/일 범위에서는 불필요한 그룹 헤더 생략(연도만이면 월 헤더 유지). A/B: 날짜는 월 헤더 안에서 월·일만 표시하는 date display variant 검토(헤더 밖에서도 날짜 해석 가능). C: 월 아래 일별 그룹, 날짜 중복 금지; 24/8 규칙 유지. 기존 row content/geometry 그대로. 일/월 경로 검색·마음 필터는 해당 범위만, 기간 컨트롤 미노출, 범위 확장 '전체 기록에서 검색'은 검토. 연도별 탐색은 전체 기록에서 기록이 있는 연도→월, 접기/월 바로가기 기능은 기간 선택 안에서 제공하며 본문을 accordion으로 바꾸지 않음. 한 해만 있는 경우 단일 CompactSelect(전체 기간+월); 여러 해면 연도 selector(전체 기간+기록 연도), 선택 연도에만 월 selector(전체 월+기록 월). 조건 변경 시 목록 시작점 이동, keyboard focus는 조작한 컨트롤에 유지.

## 검색 매칭/결과 배리언트

DiaryRow searchResult optional metadata(일치 위치/문맥/안전한 text segments). 기본 4 content variants와 surface/date/divider 상태 그대로. title match: 제목 중 일치 강조, 기존 본문 미리보기; body match: 첫 일치 주변 문맥으로 body preview 대체, 2/3줄 규칙 유지; reflection-only: 원문 제목 유지(없으면 원문 미리보기), 보조 슬롯 '덧붙인 마음에서' 13px + 매칭 문맥 14px max2, gap4. 여러 영역 일치: 제목/본문 우선, 마음 일치도 있는 경우 작은 '덧붙인 마음에도' 표시 검토, 같은 일기 복제 금지. 여러 마음 중 최신 일치 마음 1개 표시, 마음 수는 실제 총수. 검색 결과 열면 기존 DiaryContent 그대로, 원문 수정/강조 지속 없음. 검색 중 원문 긴 글 전체 렌더 금지. 문맥은 일치가 보이도록 앞뒤 grapheme 기준 추출, 시작/끝 말줄임은 생략 실제 여부에만. 320px/200% 및 긴 일치문 자체가 한 줄보다 긴 경우 clamp에서 적어도 일치 일부 노출. mark는 React text nodes로만, 기본 텍스트와 동일 글자 크기/줄 높이, accent + 500 강조(색만 금지), 배경색 없음, 대비 검사. 악성 입력/정규식 문자/이모지/분해 한글 처리; 정규화→원본 오프셋 매핑 또는 정규화된 preview 표시, 저장 원문은 그대로.
