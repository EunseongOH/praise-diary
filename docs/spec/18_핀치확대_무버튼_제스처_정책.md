# 18. 그래픽 감상: 버튼 없는 선택형 확대 제스처 (v0.6)

## 결정 상태: 확정
- 그래픽 상세 화면의 `－ / 배율 / ＋` 표시와 버튼을 **제거**한다.
- 확대 기능은 핵심 행동이 아니므로 설명 문구, 툴바, 팝업, 별도의 온보딩을 배치하지 않는다.
- **기본 상태는 1.0배**. 화면에 들어올 때 자동으로 확대하지 않는다.
- 원하면 두 손가락 벌리기·오므리기로 확대·축소한다. 확대 후 한 손가락으로 위치를 이동한다.
- 자연스럽게 원래 크기로 축소할 수 있고, 버튼으로 되돌리는 행동을 강요하지 않는다.
- 확대하지 않아도 월간 그래픽 감상·일기 목록 조회는 가능하다.

## 구현
- 공통 컴포넌트 `GestureArtwork`에서 Pointer Events 두 개의 거리와 중점을 이용해 1.0~3.2배 확대를 계산한다.
- 월별 SVG (`GraphicArtwork`)는 동일하게 재사용하며, 홈/도감 2열/저장 완료의 UI나 모션에는 영향을 주지 않는다.
- 확대·이동은 화면 영역 안에서만 일어나고 스크롤 위치가 튀지 않도록 범위를 제한한다.
- 보이지 않는 키보드 대체 경로: 포커스된 그래픽에서 + / - / 0 및 방향키 지원. 접근성 이름으로 조작법 전달하며 화면상의 버튼은 두지 않는다.
- `prefers-reduced-motion` 및 앱 움직임 줄이기 설정은 기존 파티클 모션에만 적용되며, 사용자가 직접 수행한 핀치 제스처 자체를 막지 않는다.

## 유지 사항
- 글자는 같은 일기별로 가능한 한 가까운 곳에 이어진다.
- 눈꽃 줄기의 진행 방향, 미세한 흔들림, 기록 날짜 수에 따른 아래→위 성장 규칙은 유지한다.
- 색상·그래픽 아트 디렉션은 확정되지 않았으므로 본 변경 범위에서 수정하지 않는다.

## 품질 확인
- 두 손가락으로 확대/축소할 수 있는가
- 확대 후 손가락으로 이동 가능한가
- 기본 배율로 화면 진입 시 어떤 조작 UI도 보이지 않는가
- 다시 들어가도 기본 상태로 열리는가
- 앱 내 다른 영역 스크롤/뒤로가기/월별 기록 조회가 가능한가
- Android 및 iOS 웹뷰에서 터치 취소·화면 회전·안전 영역 대응 검증(실기기 검증 필요)

기존 `17_그래픽_확대읽기_정책.md`의 확대 버튼 방식은 v0.6에서 대체되었다.
