# 디자인시스템·컬러 후보 및 개발 환경 결정 (v1.7)

**기준일:** 2026-11-21 (KST)

## 사용자 결정

- 색상 후보: `#B8D68A`, `#61AE72`, `#FFFFFF`, `#FAD89E`, `#A6C5D3`.
- 라이트 UI는 흰색 바탕을 우선한다. 저시력자의 색 대비를 확보하면서 색감은 부드럽게; 그래픽의 모티프에 따라 달라질 수 있다.
- 그래픽이 밝은 배경에서 충분히 구분되지 않으면 홈의 그래픽 감상 영역만 어두운 배경을 사용하는 안을 허용한다.
- 색상은 브랜드 최종 확정이 아니라 시각 탐색 후보임을 표시.
- TDS 외에도 SEED·Polaris·Material 3·unslop 등에서 적합한 UX·UI 원칙을 선별. 불필요한 아이콘·그라데이션·카드 반복·과한 AI식 문구 금지.
- 재사용 가능 요소(상단바, 내비게이션, 버튼, 토글, 세그먼트, 모달/다이얼로그, 토스트, 카드, 목록, SVG 그래픽 등)를 실제 컴포넌트로 묶고 기존 UX Writing을 코드 한 파일에서 관리.

## 이번 구현 [프로토타입, 프로덕션 아님]

- `src/styles/tokens.css`에 원본 5색 + AA 대비 의미 색상 추가. `design-system/color-system.md`에서 실제 대비값과 용도를 관리.
- `src/components/ui.tsx`: AppBar, BottomNavigation, Button, TextAction, SegmentedChoice, Toggle, SettingRow, Dialog, Toast, EmptyState.
- `src/components/content.tsx`: MonthTile, DiaryList, MemorySlip.
- `src/graphics/GraphicArtwork.tsx`: 진행 높이와 실제 작성 글자를 분리한 SVG 스터디(원문을 읽을 수 있는 문자열로 전시하지 않음).
- `src/content/copy.ts`: 사용자 확정 문구 일원화. 꺼내보기 잠금·날짜 안내·삭제 영향·완료·알림 준비 상태 포함.
- `src/screens/App.tsx`: 주요 화면 플로우 프로토타입. 기록·설정은 sessionStorage 데모 저장, 서버 인증·Toss SDK 연동 및 운영상 사용 불가.
- `design-preview.html`: 라이브러리 설치 없이 검토 가능한 정적 디자인 미리보기(저장 및 실제 플로우와 분리).

## 검증 결과

- WCAG 2.2 AA 일반 텍스트 기준 적용: dark text `#273C2F` on white 11.84:1, art `#A6C5D3` on `#162A28` 8.27:1, user original palette on white generally 4.5:1 미달.
- Node 구문 검사: 11개 TypeScript/TSX 파일 구문 오류 0.
- 날짜·동일 날짜 다중 일기·추첨: 9개 assert 통과.
- Chromium: 정적 미리보기 내비게이션 홈/도감/꺼내보기 전환 확인.
- `npm install`: 개발 컨테이너의 npm registry DNS 접근 불가. **실제 React 타입 검사와 Vite 빌드는 수행하지 못함.** 로컬 또는 CI에서 꼭 검증할 것.
