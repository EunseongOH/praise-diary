## 1. 12월 테마와 시각적 위계 [확정]

1. **12월의 주제는 '눈꽃'**이다. 눈꽃이 가장 먼저 보이고, 그 다음에 글자로 이루어진 조형, 마지막으로 빛나는 장식적 디테일이 발견되는 위계를 유지한다.
2. 색감은 **A(흰색·은빛·차가운 아이스 블루)**를 **기본/대부분**으로 사용한다. C(아주 옅은 하늘·핑크·라벤더·민트·노랑 등의 다색 전구빛)는 **아주 적은 수의 작은 반짝임·포인트**로만 사용한다.
3. 모든 주요 줄기·가지와 코어를 컬러 전구로 바꾸거나 눈꽃보다 다색 빛이 먼저 보이게 하지 않는다. 차갑고 조용한 겨울 결정의 인상을 보존한다. 파스텔 포인트는 작은 빛 입자 또는 일부 글자가 잠시 빛을 받는 순간에만 출현할 수 있다.
4. 사용자가 아름다운 조형을 더 중시하므로 그래픽 글자의 문장 가독성을 보존하려고 인위적인 **검은 테두리/검은 배경/어두운 후광이 붙은 것처럼 보이는 처리**를 유지하지 않는다. 배경/후광 처리의 정확한 원인과 제거 가능한 부분은 기존 Gate 2G 렌더러 코드에서 확인해야 한다.
5. 단, 글자 앞뒤의 **물리적인 깊이·가림·회전에 따른 명도 변화**는 유지한다. 검은 윤곽/배경 제거와 3D 깊이 가림 제거는 같은 작업이 아니다.
6. 기존 Gate 2G에서 사용자가 긍정적으로 평가한 **선명한 앞면 구절과 흐린 뒷면 구절의 실제 회전·교대**는 유지한다. 새로운 빛 효과를 추가하는 과정에서 모션을 정지하거나 전면 교대를 2D 페이드로 대체하지 않는다.

## 2. 빛·파티클 방향 [확정된 의도 / 구현값 미정]

- 실제 사용자가 쓴 일기 글자로 눈꽃의 주요 형태를 구성한다. **장식용 소형 빛 입자는 허용**하되, 입자가 눈꽃의 실루엣이나 원문 대신 주재료가 되어서는 안 된다.
- **글자 자체의 빛**: 일부 글자의 전면 등장·회전·깊이에 맞춰 은은히 밝아지고 어두워질 수 있다.
- **눈꽃에 결부된 작은 빛**: 중심부·큰 팔·가지·끝부분에 흩어져 서로 다른 크기·위상·밝기·수명으로 빛날 수 있다. 전체가 동시에 번쩍이거나 과한 네온처럼 보이는 것은 지양한다.
- **글자의 이동과 연동된 빛**: 일부 글자가 눈꽃 내부에서 이동하거나 결합할 때 작은 빛이 함께 반응할 수 있다. 이는 실제 글자가 아닌 파티클임을 내부 데이터·테스트에서 구분할 것.
- 차가운 계열이 우선이며 옅은 다색은 희소하게. 파티클 밀도/분포/블룸 범위/평균 동시 점등 비율/HEX/작품 크기별 가시성은 **연구에서 비교하고 사용자 미감으로 승인받는다**.

## 3. 다른 월별 콘셉트로 빠른 전환이 가능한 구조 [확정된 설계 원칙]

- 특정 월의 테마를 공통 그래픽 엔진 자체에 하드코딩하지 않는다.
- **Shape**(그달 작품의 형상), **Typography**(원문/반복/배치), **Motion**(회전·부유·교대·이동), **Lighting**(기본 색·명도·빛의 패턴), **Particles**(형태에 어울리는 작은 장식 효과)를 **역할별로 구분**한다.
- 예: 12월 눈꽃은 여섯 갈래 결정·차가운 흰빛/파란빛·드문 파스텔 광점. 다른 월은 새로운 형태, 전용 색감, 모션, 파티클 성격을 정의할 수 있어야 한다.
- 기존 diary 데이터/작성일 수 성장/대표(anchor) 원문 안정·반복(echo) 출처 추적 규칙은 월별 작품이 달라도 재사용한다.
- 각 월의 작품에는 별도 조형 정의/튜닝이 필요할 수 있으며 **테마 설정값 변경만으로 모든 새 작품이 자동 생성된다고 주장하지 않는다**.
- 공통 제품 UI의 브랜드 팔레트와 **월별 아트 팔레트는 분리**한다. 12월 눈꽃 팔레트를 버튼·탭 등 모든 서비스 UI에 강제하지 않는다.

## 4. 지금은 결정하지 않는 항목 [보류]

- 최종 HEX 값 및 색상 비율(예: 90:10은 아직 확정 아님), 파티클 크기·갯수·동시 점등 비율·잔상/광채 강도
- A/C를 합친 단일 시안과 다른 농도를 비교할 방법 및 최종 효과의 정량적 합격 기준
- 실제 검은 배경/윤곽 처리의 코드상 원인과 제거 최적화, 기존 레이어 가림·깊이 가독성의 타협점
- 성능 최적화 전략 및 모바일 기기/앱인토스 WebView 실기기 검사; Gate 2G에서 DPR2 기본 R2 약 13.9fps로 보고됨
- 첫날 눈꽃 씨앗 문제, 2026년 12월 특별 목표일 수, 다른 월별 작품의 구체 팔레트와 모션
- 다음 Gate의 상세 구현 명세·앱 제품 배포·실서비스 컴포넌트 변경. 사용자의 별도 승인 전 시행하지 않음.

## 5. 실무 협업 경계

- 기존 Gate 2A~2G의 개발 전용 구현과 산출물은 사용자 PC의 미커밋 로컬 상태에 있을 수 있다. `git status --short` → `git fetch` + `git show`로 변경 문서를 읽고, 미커밋 코드 보호를 위해 무분별한 `git pull/checkout/reset/restore/clean` 금지.
- 사용자 요청 전까지 기존 연구 코드/산출물과 실서비스 `GraphicArtwork`·홈·일기 작성·도감 등은 변경하지 않는다.
- 레퍼런스 자체는 어떠한 형태로도 GitHub에 올리지 않는다.
- 이번 문서는 **승인된 디자인 방향을 보존**한 것이며, 기술 스터디·최종 시안·성능이 검증됐다는 뜻은 아니다.
