콘솔 워크스페이스 내부 주소·ID는 공개 저장소에 기록하지 않음.

- 앱 유형: 비게임
- 카테고리: 라이프스타일 우선 검토 (실제 콘솔의 하위 카테고리 확인 전 제안)

- 슬로건: 오늘도 나에게 다정한 한 줄

## 앱 상세 설명 (접속 → 행동 → 결과)

다정록을 열고 오늘도 스스로에게 다정한 한 줄을 남겨보세요.

다정록은 하루의 작은 노력과 마음을 칭찬으로 기록하고, 그 문장들이 모여 매달 하나의 작품으로 자라는 일기 서비스예요.

오늘이나 어제의 칭찬을 자유롭게 작성하거나, 두 개의 회고 질문을 참고해 하루를 돌아볼 수 있어요.

새로운 날짜에 칭찬을 남길 때마다 작품이 조금씩 자라요. 같은 날 더 남긴 말도 작품에 더해져 나만의 글자 작품을 완성해 가요.

달력과 기록 목록에서 지나온 칭찬을 다시 읽고, 일기 10개를 모으면 ‘꺼내보기’에서 예전의 나에게 건넨 다정한 말을 무작위로 다시 만날 수 있어요.

평범했던 하루에서 잘한 일을 발견하고, 시간이 지나 쌓인 나의 다정함을 하나의 작품으로 돌아보세요.

500자 제한 이내. 실제 출시 기능과 문구를 제출 전 다시 확인.

### 이번 테스트 번들의 출시 노트
다정록의 첫 앱인토스 테스트 번들입니다. 칭찬일기 작성과 수정, 달력·도감·꺼내보기 화면, 월별 눈꽃 그래픽의 기본 동작을 검수합니다. 기록은 아직 기기 세션에만 저장되며 다른 기기로 복원되지 않습니다.

### 메모 (테스트 내부 기록)
SDK 3.x 연동 검수용. 실제 개인정보 입력 금지. 토스 인증 및 영구 저장 미연결, 정식 출시 심사 요청 전 기능·보안 재검증 필요.

## 주요 기능 문구
1. 오늘의 칭찬일기 — 오늘의 작은 노력과 마음을 나만의 문장으로 남겨요
2. 기록으로 자라는 월간 작품 — 날짜가 쌓일수록 변화하는 작품을 감상해요
3. 지난 칭찬 꺼내보기 — 내가 남긴 칭찬을 다시 읽고 돌아봐요

## 검색 키워드 후보
칭찬일기, 일기, 하루기록, 자기돌봄, 회고, 나를칭찬
(실제 콘솔의 개수/길이 제한 확인 전 후보; 의료/상담/치료 등 부정확한 표현 금지)

## 운영자 제출 필요 정보 (모두 미확정)
- 제작자 표시명, 운영 주체 법적 명칭, 워크스페이스 ID
- 고객센터 URL/운영 이메일/개인정보 문의 연락처

세로 스크린샷 후보:
1. 다크 퍼플 홈과 실제 12월 눈꽃(가상 일기만 사용)

## 제품·심사 특이사항
- 비게임 개인 일기, 결제 및 광고는 MVP에 없음
- 서비스는 심리 진단/치료/전문 상담 또는 AI 생성 상담 서비스가 아님
- 개인 기록은 공유 기능 없음(장래 공동 일기장 확장은 MVP에 미포함)
- 12월 목표 일수 아직 미정; 1월 붉은 양과 해는 그래픽 미제작; 실제 구현 전 미출시 기능 홍보 금지
- 실제 DB, 계정 삭제, 데이터 영구 저장이 연결되기 전에는 자동 동기화/복원 보장 문구 사용 금지
