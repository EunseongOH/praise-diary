콘솔 워크스페이스 내부 주소·ID는 공개 저장소에 기록하지 않음.

- 앱 유형: 비게임
- 카테고리: 라이프스타일 우선 검토 (실제 콘솔의 하위 카테고리 확인 전 제안)

- 슬로건: 오늘도 나에게 다정한 한 줄

## 앱 상세 설명 · 검수 후보 (500자 이내)

스스로에게 다정한 한마디를 남겨보세요.

바쁘게 지나간 하루에도 분명 칭찬해 줄 나의 순간이 있어요. 작은 노력과 용기, 미처 알아주지 못한 마음까지. 다정록은 그 순간들을 한 줄씩 모아두는 칭찬일기예요.

오늘의 나를 칭찬해도, 어제의 나를 돌아봐도 좋아요. 막막한 날에는 가벼운 질문이 첫 문장을 도와줄 거예요.

하루하루 남긴 문장들은 조금씩 자라 매달 하나의 작품이 돼요. 내가 건넨 다정한 말들이 어떤 모습으로 피어날지 기대해 보세요.

그리고 어느 날, 포춘쿠키를 열듯 지난 칭찬을 꺼내보세요. 과거의 내가 남긴 한마디가 지금의 나에게 뜻밖의 응원이 될지도 몰라요.

거창한 하루가 아니어도 괜찮아요. 오늘의 나에게 다정했던 순간 하나면 충분해요.

### 테스트 번들 출시 노트
개발용 테스트 번들에서 12월 눈꽃의 1·5·15일 렌더링을 직접 확인할 수 있는 미리보기를 추가했어요. 11월에는 실제 눈꽃 작품이 없으며, 미리보기는 가상 문장만 사용하고 개인 기록에는 반영되지 않아요. 사용자 인증·영구 저장은 미연결 상태예요.

### 테스트 번들 메모
11월 홈에서 12월 눈꽃이 나오지 않는 것은 현재 월 설정에 따른 정상 상태. 별도의 QA 눈꽃 미리보기에서 가상 글자 기반 렌더링과 Canvas 상태 확인. 실제 개인정보 입력 금지.

## 주요 기능 문구
1. 오늘의 칭찬일기 — 오늘의 작은 노력과 마음을 나만의 문장으로 남겨요
2. 기록으로 자라는 월간 작품 — 날짜가 쌓일수록 변화하는 작품을 감상해요
3. 지난 칭찬 꺼내보기 — 내가 남긴 칭찬을 다시 읽고 돌아봐요

## 검색 키워드 후보

## 운영자 제출 필요 정보 (모두 미확정)
- 제작자 표시명, 운영 주체 법적 명칭, 워크스페이스 ID
- 고객센터 URL/운영 이메일/개인정보 문의 연락처
- 실제 공개된 개인정보처리방침 URL과 이용약관 URL

- 최종 백엔드 공급자, 리전, 처리위탁 및 국외 이전 사항
- 앱 아이콘, 홍보용 이미지, 개인정보 없는 실제 화면 캡처

## 이미지 제출 사양 및 기획
2026-02 토스 공지의 규격 (최종 제출 때 콘솔 현행 확인):
- 비게임 정방형 대표 PNG 1000×1000
- 비게임 가로형 대표 PNG 1932×828
- 세로 스크린샷 PNG 636×1048 3장 이상
- 가로 스크린샷 PNG 1504×741 1장 이상
- 아이콘 규격(픽셀·파일 용량)은 등록 콘솔에서 직접 확인 후 제작
2026-10 이후 비게임 앱은 자동 스크린샷 생성 기능도 안내됐으나 실제 촬영 화면·노출 개인정보·잘림을 직접 점검해야 함.

세로 스크린샷 후보:
1. 다크 퍼플 홈과 실제 12월 눈꽃(가상 일기만 사용)
2. 칭찬일기 작성과 서로 다른 질문 두 개
3. 기록 10개 달성 후 꺼내보기 또는 월별 작품 도감
가로형은 다정록 브랜드 + 실제 눈꽃 + 핵심 문구로 구성. 실제 이용자 일기 캡처는 금지.

## 제품·심사 특이사항
- 비게임 개인 일기, 결제 및 광고는 MVP에 없음
- 서비스는 심리 진단/치료/전문 상담 또는 AI 생성 상담 서비스가 아님
- 개인 기록은 공유 기능 없음(장래 공동 일기장 확장은 MVP에 미포함)
- 12월 목표 일수 아직 미정; 1월 붉은 양과 해는 그래픽 미제작; 실제 구현 전 미출시 기능 홍보 금지
- 실제 DB, 계정 삭제, 데이터 영구 저장이 연결되기 전에는 자동 동기화/복원 보장 문구 사용 금지
