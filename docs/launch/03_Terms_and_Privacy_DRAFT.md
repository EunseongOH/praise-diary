**아직 공개하거나 콘솔에 등록하지 말 것.** 실제 운영 주체, 공급자, 서버 리전, 백업 기간, 계정 탈퇴/삭제 구현과 법률 검토 완료 후 최종화한다. 본 문서는 완성된 법률 자문이나 개인정보 처리방침이 아니다.

## 서비스 이용약관 (작성 초안)

### 1. 서비스 내용
다정록은 사용자가 스스로를 칭찬하는 글을 작성하고, 작성한 기록을 기반으로 달마다 만들어지는 시각 작품을 감상하며, 이전에 쓴 기록을 다시 읽는 서비스입니다. 본 서비스는 의료·정신건강 진단이나 전문 상담·치료를 제공하지 않습니다.

### 2. 이용과 데이터 귀속
서비스 이용은 앱인토스가 지원하는 식별 절차와 연결됩니다. 사용자가 작성한 일기는 해당 사용자에게만 보이는 것을 기본으로 하며, 공개·공동 일기장 기능은 현재 MVP에서 제공하지 않습니다. 단말기 변경 시 데이터 유지 및 복원은 실제 클라우드 보관이 완료된 후 정확히 규정합니다.

### 3. 이용자 권리와 의무
사용자는 자신의 기록을 작성·수정·삭제할 수 있고, 서비스는 정상적인 데이터 보관·복원·문의 절차를 제공합니다. 입력 내용은 사용자 자신의 기록으로 사용되며, 다른 사용자의 개인정보·권리를 침해하는 방식으로 사용하지 않아야 합니다.

### 4. 변경·장애·종료
서비스 변경, 점검, 종료 시 사용자에 대한 고지 방법과 데이터 내려받기/탈퇴를 지원할 시기를 정합니다. 서비스 운영자의 면책·책임·분쟁 해결 및 약관 변경 조항은 실제 법무 검토 후 확정합니다.

## 개인정보처리방침 (작성 초안)

### 개인정보처리자 / 시행일
- 개인정보처리자: [실제 개인/사업자 법적 명칭]
- 연락처·문의 채널: [실제 이메일/고객센터]
- 시행일: [실제 배포일]

### 처리 항목
- 계정 확인: 앱인토스 서버 검증을 통해 얻은 식별값으로부터 생성한 비가역적 서비스 UID, 인증 시각·세션 관련 정보
- 이용자가 직접 입력한 내용: 기록 날짜, 칭찬일기 제목·본문, 선택한 질문, 덧붙인 회고, 그래픽 제안
- 서비스 이용 설정: 날짜 경계 시각, 모션 선택, 꺼내보기 최초 개방 정보, 월별 작품 소개 이력
- 기록으로 만들어진 작품 이미지·메타데이터: 기기 캐시 또는 서버 보관이 실제 결정되면 그 범위 및 보존 기간 기재
- 오류/운영: 개인 글 본문을 포함하지 않는 최소한의 장애 정보와 서버 요청 처리 정보

### 처리 목적
사용자 기록의 작성·조회·수정·삭제, 월간 그래픽 생성, 꺼내보기·도감 등 기록 열람, 설정 유지, 서비스 장애·고객 문의 처리. **입력 원문을 마케팅·모델 학습·광고 분석에 사용하지 않음.**

### 접근 제어와 원문 보관
기본적으로 자기 기록만 볼 수 있고 다른 사용자에게 공개하지 않음. 운영자의 원문 열람 접근도 최소화하며 서버 인증·DB 권한 규칙·암호화된 통신 및 저장·접근 로그 보호를 구현 후 명시. 종단간 암호화(E2EE)를 실제 구현하지 않은 경우 E2EE라고 표현하지 않음.

### 보존·삭제
- 서비스 이용 중 보관 여부, 사용자가 단건/전체 삭제할 때의 처리 기간: [실제 구현·운영 정책 확정]
- 토스 계정 연결 해제, 서비스 탈퇴/재가입/사용자 계정 삭제 시 개인 기록 파기: [SDK 콜백 확인 및 서버 삭제 검수]
- 서버 백업, 복원본, 기기 캐시 및 썸네일의 보존·삭제 기간: [최종 공급자 운영 정책 및 기술검증]
- 보존 법령/법정 보유 사유가 있다면 분리 보관하고 처리 목적을 정확히 기술

### 개인정보 처리위탁 및 국외 이전
[Firebase/Google Cloud 또는 Supabase 등 최종 사업자, 법적 명칭, 저장 리전, 처리위탁 범위, 국외 지원·로그·백업 접근 여부, 계약상 책임 및 이용자 안내]를 최종 확정한 후 기재. 한국 DB 리전 선택 자체가 모든 개인정보 처리의 국내 한정은 아님.

### 정보 주체 권리
본인 기록 열람·수정·삭제, 제공하는 경우 내보내기, 동의 철회 및 처리 정지·민원 접수 방법, 응답 기한, 권리 행사 담당자 연락처를 실제 기능과 일치시켜 명시.

### 미성년자·민감 기록
사용자의 자유 텍스트에 건강 상태·감정·가족 이야기 등 민감한 내용이 들어갈 수 있음. 14세 미만 아동의 서비스 이용과 법정대리인 동의 필요 여부, 민감정보 처리 관련 법적 근거·수집 최소화는 출시 전 별도 법률 검토.

## 실제 최종화 전 점검
- 실제 고객센터·법적 운영자 이름/주소/이메일을 기입
- 채택한 DB 공급자·영구 저장/백업/보존 기간·약관과 코드 동작 일치
- 서버 인증 실패 및 원문 저장 실패에서 데이터 손실 위험 고지/대처
- 토스 식별키, Firebase Auth, 클라우드 스냅샷, 앱 단말기 저장소 정책의 보안·파기 검토
- 개인정보처리방침 URL/이용약관 URL 실제 공개, 앱 내 접근 가능
- 가짜 예시 문구나 출시하지 않은 기능을 운영 사실처럼 기술하지 않기
