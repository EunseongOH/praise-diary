# 앱인토스 운영팀에 확인할 문의 초안

이 문서는 운영 문의를 보낸 내역이 아니라 요청 시 채널톡/개발자 커뮤니티로 복사해 제출할 사전 질문지다.

## 문의 제목
[비게임 WebView] 다크 작품 중심 일기 미니앱의 테마·인증·외부 폰트·내비게이션 검수 기준 확인

## 문의 내용
안녕하세요. 비게임 WebView 기반 '다정록'이라는 개인 칭찬일기 미니앱을 출시 준비하고 있습니다. React/Vite로 개발한 UI를 앱인토스 SDK 3.x에 연결하기 전에 몇 가지 기준을 확인 부탁드립니다.

1. **비게임 라이트 모드 정책:** 다정록은 사용자가 작성한 문장으로 눈꽃 작품을 만드는 서비스여서 전체 화면을 다크 퍼플 캔버스로 설계했습니다. 비게임 체크리스트에서 미니앱 테마를 라이트 모드로 구현하도록 안내하고 있는데, 작품 감상용 화면에서의 어두운 배경은 예외로 가능한지, 작품 외 홈·일기 작성·설정 UI까지 밝은 테마로 구현해야 하는지 문의드립니다. 토스 NavigationBar는 공식 설정을 사용할 예정입니다.
2. **익명 인증 코드:** 비게임에서 User.createAnonymousKeyAuthCode()를 사용하려고 합니다. 최소 토스 앱/SDK 버전, 미지원 버전 대응 방식, 기기 변경 시 동일 식별자 기준, 앱 탈퇴/연결 해제 시 서버에 알림을 받을 수 있는 콜백 또는 탈퇴 처리 권장 방식이 궁금합니다. 클라이언트 getAnonymousKey()만으로 서버 접근을 허용하지 않고 서버 mTLS 교환 후 자체 세션을 발급할 예정입니다.
3. **외부 폰트:** 미니앱 번들 안에 라이선스가 허용하는 Pretendard/고운바탕 글꼴을 자체 호스팅하는 방식과, 현재 공개 CDN 폰트 스타일시트를 사용하는 방식 중 허용 가능한 형태가 무엇인지 문의드립니다. Toss Product Sans 글꼴 파일은 임의로 포함할 계획이 없습니다.
4. **진입 애니메이션:** 최초 방문에 창가 스플래시 및 작품 소개를 약 8.5초 동안 표시하되 안내 장면 이후 건너뛰기를 제공하고, 이후 재방문에는 약 0.8초 브랜드 스플래시만 표시할 예정입니다. 첫 진입 시간·자체 로딩 화면에 관한 별도 제한이 있는지 문의드립니다.
5. **내비게이션:** 앱 내부 월별 작품 상세/작성 화면의 뒤로 가기 상태를 공식 NavigationBar backEvent와 연결하려 합니다. 자체 AppBar에 뒤로 버튼을 또 두지 않는 구성이 적절한지 확인 부탁드립니다.
6. **서버 API 및 캐시:** 로그인 검증·개인 일기 DB를 외부 서버와 연결하며, WebView의 Origin에 대해 서버 CORS 허용 목록을 운영하려 합니다. 실제 정식 origin과 QR/샌드박스 테스트 origin에서 별도 설정이 필요한 부분이 있다면 안내 부탁드립니다.

출시 전 공식 개발자센터 체크리스트와 답변을 반영하겠습니다. 감사합니다.

## 제출할 때 첨부
- 다정록 홈·일기 작성·도감 화면 캡처 (실제 사용자 기록이 아닌 가상 텍스트만 포함)
- 다크 캔버스와 내비게이션 대비를 보여주는 실제 앱 화면
- 현재 실제 SDK 버전 / 토스 앱 Android·iOS 버전 / 콘솔에 등록한 appName (확정 후)
- 문제가 있는 항목마다 QR 테스트 방식, 재현 방법 및 스크린샷
