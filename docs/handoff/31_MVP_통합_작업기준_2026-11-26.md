# 다정록 MVP 통합 기준 (2026-11-26)

## 브랜치
[확정] main = 검수된 기능들의 통합 브랜치. 기존 feat/design-system-prototype는 이전 UI/그래픽 연구 보존용이며 강제 갱신·삭제하지 않는다. feat/mvp-integration에서 앱 통합 작업. 기능별 변경을 작은 커밋으로 검증한 뒤 main 대상 PR에서 병합한다. 기존 draft #1은 별도 연구 브랜치로 유지. 사용자 로컬 미커밋 파일이 있을 수 있으므로 reset/clean/force push 금지.
[확정] 월간 타이포그래픽 렌더러는 이번 통합에서 제외. 홈·저장 성공·도감·월 상세·확대 상세에 동일한 ArtworkSlot 계약을 두고 나중에 승인된 렌더러를 연결한다. 화면 크기와 월별 원본 일기·고유 기록일·기존 진행일·reducedMotion을 전달할 수 있게 한다. 플레이스홀더는 가짜 완성 그래픽을 만들지 않는다. 꺼내보기의 기억병은 월간 아트와 별개로 V10 시안을 기준으로 구현할 대상이다.

## 실제 화면 통합 순서
1. Foundation: 공통 토큰, SVG 아이콘, IconButton, Stack/Inline, FieldShell/Textarea, ActionGroup, ActionMenu/MenuItem, typography. v0.5 > v0.4 > v0.3; 공통 소스와 화면을 함께 맞추고 회귀 테스트. 기존 React CSS는 레거시이므로 전부 최신이라고 판단 금지.
2. 홈/달력: 월 선택 왼쪽, +/달력-작품 전환/설정 오른쪽. 달력에는 작품 제목 없음; 기록일만 은은 표시; 기록일 탭→해당 날짜의 목록→공통 원문 감상; 돌아오면 같은 달/모드 유지. +는 실제 오늘/어제 신규 작성. 과거 월 CTA 이달의 칭찬 보기. 전체 기록은 꺼내보기 잠금과 독립. 미래 월 잠금. 하단 3탭 홈/꺼내보기/도감.
3. 작성: 선택 제목 + 제목 추가, 회고 질문 하단 접힘 2개, 원문 자동삽입 금지. 저장 후 기록일에 맞는 작품 영역(현재 슬롯) 및 성공 피드백. 글자 입력과 날짜 선택의 미저장 방어.
4. 데이터/공통 감상: 단일 entry ID 기반, Reflection 1:N. 원문과 덧붙인 마음을 같은 종이에서 날짜순 표시, 원문 수정/삭제와 마음 수정/삭제는 독립. 마음은 월 성장/10편 해제/추첨/병 쪽지 수에 포함하지 않음. 원본 삭제 시 연결 마음 삭제 및 사전 안내. 미저장 확인, 오류 재시도, 세 진입점 복귀.
5. 꺼내보기: V7-B 유리, V7-1 코르크, A1 쪽지, B 구도; 안쪽 풀림 4:3, 길면 세로 확장. 10개 최초 달성 후 재잠금 없음. 0/1/3/5장 시각 구간은 검토안. 추출된 쪽지에 지지되던 나머지만 내려앉는 모션. 읽는 동안 병은 초기화; 닫으면 닫힌 병, 다시 뽑기 버튼 없음. 마음 덧붙이기 MVP 포함(달력·전체 기록에서도 가능). V10의 입력과 ActionMenu 규격 참조.
6. 도감/설정: 2열 작품 슬롯·미래 잠금·월 상세·기록 접근. 별도 채팅의 최종 시안/코드를 확인 후 통합. 날짜 경계, 움직임 줄이기, 기록 관리, 읽기 서체 개인화(후보별 검토). 알림 플래그 OFF.
7. 백엔드/SDK: 인증, RLS, durable save, 오류/복구, 실제 기록 데이터 보호, Toss 검증. sessionStorage 프로토타입을 출시용 저장소로 사용하지 않는다.
