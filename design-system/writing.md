# UX Writing 결정 사항

표시 문자열의 1차 소스는 `src/content/copy.ts`. 이 파일에서 사용자-facing 카피와 기능별 분기 로직을 관리한다.

- 홈 미작성: **오늘의 칭찬 남기기**
- 홈 작성 후: **칭찬 하나 더 남기기**
- 홈 기록 진입: **내가 남긴 칭찬 보기**
- 꺼내보기 잠금: **나에게 남겼던 칭찬 중 하나를 되새겨볼 수 있는 공간이에요. 남겨진 칭찬이 많아지면 볼 수 있어요.**
- 잠금 CTA: **칭찬일기 남기러 가기**
- 날짜 설정: **하루가 바뀌는 시간** / **늦게 잠드는 편이라면 하루가 끝나는 시간을 늦출 수 있어요.**
- 날짜 설정 적용: **앞으로 쓰는 일기부터 적용돼요. 이미 남긴 기록의 날짜는 그대로예요.**
- 12월 마지막 일기 삭제: **12월의 눈꽃이 조금 녹아요.**
- 1월 마지막 일기 삭제: **1월의 붉은 양이 조금 작아져요.**
- 날짜 인정 유지 삭제: **이 일기를 삭제하면 그래픽에서 해당 글자가 사라져요.**
- 미공개 테마: **이런 그래픽은 어때요? 의견 남기기** (보조 텍스트 액션)
- 알림 신청 제안(정책 승인 전 UI 비노출): **하루를 돌아볼 시간을 정해둘까요?** / **원하는 시간에 칭찬일기를 떠올릴 수 있도록 알려드려요. 이미 칭찬을 남긴 날에는 보내지 않아요.**
- 알림 사용/시간 설정은 앱인토스 기능성 메시지 정책 승인 전까지 `FEATURE_NOTIFICATION=false`.
- 사용자 일기 내용은 AI가 요약/수정/추천 인용하지 않는다. 랜덤 꺼내보기는 원문만 사용.
