# v0.8 검토안 — 회고 질문 / 마음 개수 / 도감 정렬
- 질문 2개, 서로 다른 범주, 다른 질문 보기 클릭 시 직전 2개 제외. 기존 refresh SVG와 TextAction 재사용. 질문 그룹 gap8, 마지막 질문→다른 질문 보기 8, 우측 정렬, 44px 이상. 선택한 질문은 현재 목록과 독립. 새 질문/펼침/닫힘은 원문을 변경하지 않는다.
- 제안 B: 선택 질문의 정확한 문장을 referencePrompt(선택적 문자열)로 일기 원문과 별개 저장. 선택 해제 시 없음. 기존 일기는 소급 추정 금지. 수정 시 기존 질문 보존 또는 X 제거. 원문 하단과 추가 기록 사이, 원문→메타 12px, 메타 내부4px, 13px/400/1.5, 기존 muted/quiet. 성장·추첨·기록일·검색 등 원문 집계에는 포함하지 않는다. 해당 질문에 답했다는 단정 대신 '글을 쓸 때 참고한 질문'. DB 연결 시 nullable 속성으로 검토.
- 덧붙인 마음 수는 실제 연결된 행 수에서 파생, 0이면 표시 없음. 날짜와 8px, 기존 message inline 16px와 숫자 사이4px, 13px/400, muted, 클릭 영역 아님. A/B는 날짜 옆, C는 개별 일기 제목/본문 옆 (날짜 그룹 전체의 합계로 오해 방지). 긴 문구 줄바꿈; 스크린리더용 이름. 수정은 수 유지, 삭제는 즉시 반영. 공개 댓글·알림·보상 아님.
- 도감 정렬 제안: 현재 월(0일 포함) → 과거 월 내림차순 → 미래 예정 월 오름차순. 미래 잠금은 유지하고, 과거/현재 테마 미정이어도 기록 조회 가능. 작품 슬롯은 유지. 달력/홈의 월 선택 순서는 변경하지 않는다. 완성도 기준으로 재정렬하지 않는다. 카탈로그 공개 기간/빈 과거 달 포함 범위는 별도 확정 필요.
- 신규 시각 요소는 기존 Icon/TextAction/Stack과 동일 색·타입·spacing 토큰 조합; 새로운 독립 조작 컴포넌트 없음. 검수안이며 사용자 승인 전 정책 확정 아님. 320/390/430 브라우저 및 기존 회귀 검사, 실기 별도.
