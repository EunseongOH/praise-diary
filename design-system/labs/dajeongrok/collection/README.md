# 다정록 도감 UI 스터디 v0.2

- 원본: [v02.html](./v02.html) — 2026-11-26 보존. 독립 실행 HTML; 내려받아 브라우저에서 열기.
- 기준: [최신 UI/UX 결정](../DECISIONS.md), [foundation v0.3](../foundation/package-v03/README.md), [도감 제품 명세](../../../../docs/spec/05_C01_그래픽도감_화면명세.md).
- v0.1 그린 계열 시안은 시각 기준으로 대체됨. v0.2는 다크 퍼플 후보 팔레트, Pretendard/Gowun Batang을 적용한 비교 실험이며 디자인 승인·실제 React 통합을 의미하지 않음.
- A안: 기록 작품과 다가오는 달을 분리. B안: 월별 연속 2열 그리드. A안은 추천 후보이며 사용자 최종 선택 전.
- 5개 이용 상황, 320/375/390/430px 너비, 월별 상세/기록 조회 및 미공개 월 의견 입력의 시연을 포함. 개발용 비교 컨트롤은 제품 UI가 아님.
- 가상 일기와 임시 작품을 사용. 실제 서버 저장/제안 제출, 최종 월간 렌더러, 실제 앱인토스 WebView 및 웹폰트 로딩 검증은 별도.
- 확정된 제품 정책(2열, 완성/미완성 보관, 고유 기록일 계산, 미래 미공개, 오늘/어제 신규 작성)은 유지한다. 빈 과거 월 노출, 미래 월 개수와 배치, 상세 비주얼 및 컴포넌트 통합은 제안/검토 단계.
- 다른 세션과 협업 시 최신 브랜치 및 DECISIONS.md를 확인한다. 이 파일은 실험 아카이브이며 기존 src, 홈/작성/꺼내보기, foundation 원본을 변경하지 않는다. 후속 시안은 새 버전 파일로 보존하고 변경 이유를 기록한다. 실제 앱 통합 전 토큰/컴포넌트 재사용 및 접근성 검증 필요.
