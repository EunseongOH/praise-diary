# 다정록 L-01–L-02 · 롤 쪽지 리파인먼트 V3

## 1. 확정 사항 (사용자 결정)
- 병 A: 짧은 목과 둥근 어깨를 가진 기억병. 기존 병 실루엣·코르크 유지.
- 쪽지 A: 작은 롤. 병과 독립적으로 설계.
- 펼침 B: 말린 쪽지가 부분적으로 실제 풀리고, 잔잔한 어두운 편지지로 전환.
- 원문 감상 Pretendard 16px / 1.75 / 400 / 0em. 제목 선택 사항, 원문 줄바꿈 보존.
- 10개 최초 해제, 영구 해제 이력, 0개 빈 상태, 1개 다시 뽑기 숨김, 최대 4장 대표 시각화. 추첨 후보는 실제 개별 일기.
- 기존 잠금 문구·색상·내비게이션·44px 독립 조작 영역·52px CTA 유지.

## 3. 모션 타임라인 (제안값)
| 구간(ms) | 상태 |
|---|---|
| 0–260 | 선택된 쪽지의 작은 움직임, 마개 열림 시작 |
| 50–620 | 코르크 수직 상승 후 왼쪽으로 이동 및 기울어짐 |
| 240–700 | 선택 쪽지 병 안쪽에서 세로 정렬 |
| 640–1130 | 병목 통과, 롤 형태 유지 |
| 1120–1430 | 병 밖에서 가로 정렬·확대, 병 서서히 사라짐 |
| 1430–2070 | 종이 바깥 끝부터 실제 곡률 변화. 최대 94% 풀림. 1770ms 이후 읽기 종이색과 연결 |
| 2070–2480 | 실제 읽기 패널의 위치·크기로 이동(FLIP 방식과 유사), 곡면/패널 교체 구간 90ms |
| 2470–2700 | 원문·감상 행동 노출. 종료 후 실제 DOM 감상 화면으로 전환 및 포커스 |

2.7초는 이번 검토를 위한 기본값이며 출시용 확정 시간이 아니다. B안이므로 마지막에는 실제 종이의 물리적 크기를 유지하는 것이 아니라 UI 패널 크기로 보간한다. 원문을 표시하기 전까지 별도 읽기 패널은 inert/aria-hidden. 사용자 탭 이동 시 재생 취소. 시각화와 샘플 추첨 분리.

## 4. 코드 분리 경계
- `designs.round` / `art`: 기존 병의 실루엣, 유리, 코르크, 내부 쪽지 위치. 병 그래픽과 UI 아이콘 토큰은 별도.
- `PAPER`, `paperCurve`, `paperSurface`, `noteShape`: 독립 종이 geometry/투영/렌더링. 정지 상태의 롤과 움직이는 쪽지가 같은 모델을 사용.
- `startMotion`, `applyFrame`, `tick`, `finish`, `stop`: 단일 시간축, 상태 전환, 재생/취소. 운영용 앱에서는 검토용 컨트롤을 제외하고 requestAnimationFrame 정리 및 reduced-motion 정책 유지.
- `reading`, `resultContent`: 읽기 패널과 원문 표시. DOM 기반 텍스트 레이아웃을 유지. SVG에 실제 일기 텍스트를 그리지 않음.
- `motion.target`: 이미 확정된 실제 추첨 결과(시안에서는 샘플); 애니메이션의 쪽지 인덱스는 별도 장식 상태.
- 지금은 단독 HTML 안에서 함수별 분리. 추후 React의 `BottleArtwork`, `PaperSurface`, `DrawMotion`, `DiaryContent` 경계로 이관. 기존 저장소는 수정하지 않음.

## 5. 검증 및 남은 과제
Chromium에서 실제 렌더링 및 다음 동작 확인: 일반 추첨과 직전 기록 제외, 9→10 작성 후 최초 해제, 1개/0개, reduced motion, 타임라인 구간 이동·일시정지, 320px 긴 글의 세로 스크롤 및 가로 넘침 없음. JS 오류 없음. 프레임 캡처로 병목 통과/부분 펼침/감상 전환 확인. 기존 CTA와 결과 CTA가 겹쳐 보이던 문제는 기존 CTA의 페이드 및 inert로 수정.

웹폰트는 외부 CDN에 의존하며 테스트는 대체 서체로 실행. 실제 앱인토스 WebView, 저사양 기기의 FPS, 터치/스크린리더 전체 테스트, 전체 React 통합 및 실제 백엔드 연결은 하지 않음. SVG 리본은 실제 3D 물리 시뮬레이션이 아닌 기하학적 투영이며, 선·색·종이 끝의 말림은 사용자 시각 검토 후 추가 리파인. 긴 글은 실제 종이가 늘어나는 것처럼 묘사하는 대신 UI 패널로 전환하여 읽기 공간 확보.
