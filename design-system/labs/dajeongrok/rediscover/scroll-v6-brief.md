# 다정록 L-01~L-04 · V6 Glass & Material Refinement

2026-11-25 / 디자인 검토용 / 기존 React 앱 미통합

## 1. 문제와 변경 범위
- 기존 V5는 유리병의 선과 안쪽 쪽지의 음영이 독립적이어서, 유리가 쪽지 앞에 있다는 인상이 약했다. 코르크 단면 및 병목 접합 표현도 단순했다.
- [확정] A 둥근 병, A1 부드러운 롤, B 나란히 쌓인 구도(최대 세 장), 안쪽으로 풀리는 방향, 4:3 원지, B 어두운 편지지. 기존 해제 정책/문구/폰트/타이포/여백은 유지.
- [제안] 기본 V6 재질: 유리의 반사·투과와 코르크 드로잉을 보완. V5 기존 재질 및 V6 반사 강조 옵션은 검토 도구에서만 제공.

## 2. 시각 설계
| 레이어 | 역할 | 규격/방법 |
|---|---|---|
| 병 후면 | 실루엣·후면 유리의 투과색 | 기존 A 경로와 외곽선 유지, 기존 후면 약한 색조 |
| 쪽지 | 종이 자체의 조형 | A1 곡면·겹침선 유지, B 좌표와 가림 순서 유지, 유리 효과를 쪽지 자체에 굽지 않음 |
| 유리 전면 | 실제로 유리 너머라는 인상 | 병 윤곽 clipPath 안에서만 투과색, 반사 리본, 바닥 음영, 전면 라인워크를 합성. 쪽지의 위를 자연스럽게 지나감 |
| 전면 반사 | 얇고 절제된 빛 | SVG 좌표 기준 측면 투과 최대 .13, 왼쪽 반사 최대 .20, 오른쪽 최대 .14; 정제 모드 반사 면 .78 배. 강한 모드는 1 배 및 일부 선의 명도 증가. |
| 병 바닥·목 | 유리의 두께감 | 바닥 안쪽 곡선/외곽의 관계, 밑면 반사, 목 내부 선, 앞/뒤 입구 타원 분리 |
| 코르크 | 따뜻한 무광 재질 | tapered side, 타원형 단면, 제한된 색면 음영, 일정한 seed의 비정형 짧은 선과 작은 pore, 목 입구 전면 선이 마개 하단을 가림 |

원칙: 강한 광원/글로우/과한 광택/외부 소품 금지. 불투명하게 칠한 병처럼 보이지 않도록 배경이 투과되게 한다. 종이 원본은 분리 보관. 마개는 병에 꽂힌 물체로 움직이고 질감도 같이 이동한다. 병 밖으로 나온 쪽지에는 전면 광학 레이어가 붙어 다니지 않는다. 실제 굴절/물리 시뮬레이션은 이번 단계에서 제외하고 라인워크와 투과 합성으로 검증한다.

## 3. 모션 (V5 기준 그대로)
0–260ms 선택, 50–530ms 코르크 이동, 240–700ms 병 안 정렬, 640–1130ms 목 통과, 1120–1430ms 가로 정렬, 1430–2070ms 풀림, 2070–2480ms 감상지 위치/크기 연결, 2470–2700ms 원문 표시. 고정 길이 48, 폭 64의 종이 곡면을 사용. 모션 감소 시 원문 직접 표시. 긴 원문은 4:3 최소 높이에서 세로 확장.

## 4. 구현 구조
`materialDefs`(인스턴스별 고유 gradient ID), `corkV6`(코르크 독립 드로잉), `glassV6`(전면 광학 그룹), 기존 `paperSurface`와 `art` 조합. `materialMode` 세 모드 및 `renderComparisons` 동일 B/A1 조합. 선택지는 랩 전용. 타임라인 역방향 탐색 시 원문 오버레이 opacity/transform 초기화도 보완.

## 5. QA / 승인 기준
- 동일한 A병·A1·B 구도에서 V5 / V6 정제 / V6 강조 비교. 전면 반사가 쪽지에 겹쳐야 하며 유리 윤곽 밖에 없어야 한다.
- 선택 쪽지가 병 밖으로 나온 뒤 유리 반사에 의해 계속 밝아지거나 흐려져서는 안 된다. 코르크 텍스처가 마개와 함께 이동해야 한다.
- 펼침이 안쪽 면을 향하고 2070ms 시점의 원지 bbox 64×48, 2700ms 정상 원문 전환. 역방향 스크럽 후 읽기 오버레이 숨김.
- 기록 0/1/50개(0/1/3장), 1개 기록에서 다시 뽑기 없음, 320px 긴 글 가로 넘침 없음, 모션 감소.
- Chromium 자동 확인: 위 기본/모드/모션/4:3/0·1·50/320px 및 JS 오류 없음 확인. 외부 폰트 요청을 차단한 테스트 환경; 실제 폰트, 앱인토스 WebView, 모바일 GPU 성능, 주관적 미술 품질은 미검증. 실제 앱 통합 전 사용자 승인 필요.

## 6. 후속
- 정제/강조 비교 후 광택 강도 및 선 밀도 조정. 필요할 경우 쪽지 배치 미세 조정, 유리 가장자리의 극미세 굴절 검토. 현재는 라인워크와 클리핑 중심이며 굴절은 구현하지 않음.
- 승인 후 공통 React 컴포넌트(BottleArtwork / CorkArtwork / GlassFront / PaperSurface / DrawMotion / DiaryContent)로 통합. 원본 데이터와 시각 쪽지 수는 계속 분리. 원문은 분석 이벤트에 전송하지 않는다.
