# 다정록 · 꺼내보기 UX 시안 v0.1

상태: 기존 확정 정책 유지, 화면 형태·문구·연출은 비교 제안. 리포지터리 원본 수정 없음.
기준: `docs/spec/02_L01_꺼내보기_화면명세.md` (feat/design-system-prototype, 확인본 v1.6 변경 포함), 디자인 시스템 v0.3 및 이후 Pretendard 감상 서체 결정.

## 확정 정책
- 활성 일기 10개 최초 달성 시 영구 해제. 날짜가 아니라 entry_id 단위. 삭제 후 9개 이하라도 다시 잠그지 않음. 서비스 전체 사용자 기록 삭제 정책에 따라 해제 이력도 초기화.
- 해제 계정 후보 0개: 별도 빈 상태. 1개: 다른 칭찬 꺼내기 숨김.
- 랜덤 기능만 잠금; 전체 기록 조회는 독립 경로에서 가능. 잠금 화면에는 목록 CTA 없음.
- 원문, 제목(있는 경우), 날짜, 줄바꿈 그대로. 인위적 요약이나 평가 없음.
- 읽기: Pretendard 16px / 400 / 1.75 / 0em, 제목 20px / 500 / 1.5 / -0.01em. 브랜드와 작품 제목은 고운바탕 유지. 추후 서체별 family/size/leading/weight/tracking 묶음과 예문 미리보기 설정을 별도 구현.

## 비교 제안
| 상태 | 시안 |
|---|---|
| L-01-LOCK | 기능 소개, 10개 조건을 문장으로 표시(표시 여부 비교 가능), 작성 CTA. 숫자 진행률 없음. |
| L-01-UNLOCK | 처음 방문 시 인라인 소개, 강제 팝업 없음. 첫 추첨 후 일반 상태. 실제 저장 직후 안내 방식은 보류. |
| L-01-READY | 닫힌 표상, 한 줄 안내, 주요 CTA 1개, 모든 칭찬 보기 텍스트 액션. |
| L-02 | 동일 화면 상태 전환, 원문을 열린 배경에서 읽기, 다른 칭찬 / 상세 / 전체 목록. X로 원문 닫기. |
| L-01-EMPTY | 현재 후보 없음 안내와 작성 CTA. |
| L-01-ERR | 요약 또는 추첨 실패 안내, 재시도. |

A: 닫힌 편지의 덮개가 열리고 종이가 올라옴. B: 접힌 종이가 펼쳐짐. C: 쌓인 기록 중 한 장이 올라옴. SVG는 비교용 임시 표상. 움직임 약 0.92초, 본문 페이드 0.36초. 실제 데이터 응답 이전에 성공 화면 표시 금지. 모션 감소는 즉시 전환. 동시 추첨 방지, 이탈 시 진행 중 연출 취소. 추첨 결과는 화면 전체의 자연스러운 스크롤로 읽음; 카드 내부의 고정 높이 금지.

## 컴포넌트 분리 제안 (React 통합 전)
- RediscoverScreen: 상태 분기, 탭 복귀 문맥 및 요청 수명 관리.
- DrawArtwork: concept / phase / reducedMotion; 접근성 장식 처리.
- DrawEntryContent: 공통 DiaryContent + 원래 날짜, 제목 유무.
- RediscoverActions: CTA 1개 및 보조 텍스트 액션. 후보 1개 조건.
- UnlockCopy: 잠금·최초 해제·빈 상태에 따른 문구.
- v0.3의 Button, IconButton, Text, DiaryContent, Stack, Inline, BottomNavigation 재사용. 44px 독립 버튼, 24px nav icon, 52px CTA 최소 높이, 20px gutter, 8px 조작 요소 간격, 24px 영역 간격. 포커스 링은 내부 2px. 색상은 기존 후보값.

## 보류
- A/B/C 그래픽, 안내 문구, 10개 조건 노출, 최초 해제 직후 토스트/인라인 방식, 열린 원문에서 상세 이동 중복 여부.
- 작성 후 후보 포함 시점, 균등 확률/가중치, 최근 중복 회피 길이. 시안은 개별 후보 균등 및 직전 1개 제외(가능할 때), 긴 글/무제 우선은 QA 전용 옵션. 실제 서버 추첨 아님.
- 홈·도감·작성·목록·상세 연동은 시연 전용. 작성·수정·삭제 및 서버 영구 저장은 미구현. 탭 복귀 시 원문 유지 가안.
- 서체 선택 기능은 전체 기능 플로우 완성 후.

## 검증
Chromium / Playwright, 외부 폰트 로드 차단 상태: 3종 연출, 직전 중복 회피, 목록-상세 복귀, 9→10개 해제, 해제 후 3/1/0개, 오류 재시도, 홈 독립 목록 접근, 320/390/430px 긴 글 스크롤/가로 넘침 및 44px 버튼, 무제 기록, 모션 감소 동작, JS 오류 없음 확인. 실제 모바일 WebView 및 정확한 웹폰트 표시, 서버 데이터·보안·영구 해제 검증은 후속.
