## [확정] 잠금 문구
하루하루 나에게 다정한 말을 모아두어요.

문득 하나를 꺼내 읽는 날,
잊고 있던 좋은 순간들이
다시 나에게 힘이 되어 줄지도 몰라요.

조건: 10개의 칭찬이 모이면, 하나씩 꺼내볼 수 있어요.
현재 개수(제안, 시안에서 표시 여부 비교): 지금까지 N개의 칭찬이 쌓였어요. 0개: 첫 번째 칭찬을 기다리고 있어요. 1개: 첫 번째 칭찬이 담겼어요.
CTA: 칭찬 하나 남기러 가기. 16/14/13px 기존 위계, 20px gutter, 52px 최소 CTA, 44px 독립 조작 영역.

## [확정 방향 / 구현 제안] 편지 스택
- 0개 0장, 1~3개 실제 개수, 4~5개 4장, 6~9개 5장, 10개 이상 6장. 상한 6장. 대표 오브젝트이며 데이터와 일대일 대응하지 않는다.
- 중앙 기준 x축 좌우 배치, 작은 y축 오프셋, 회전 ±19도 이내. 위치는 안정적이며 무한 높이 증가 없음. SVG 기준 300×206. 320px 화면에서는 축소.
- 잠금 상태도 실제로 모인 편지는 선명하게 표시; 자물쇠나 수치 진행바 없음.
- 추첨: 서버 구현 전 로컬 샘플 후보 중 선택. 시각적으로 뽑히는 봉투는 실제 후보 ID와 무관. 전체 후보가 추첨 대상이며 6장으로 제한되지 않음. 직전 동일 기록 회피는 제안값.
- 연출: 0~480ms 한 장 선택/중앙 이동, 약 460~810ms 플랩 열림, 720~1370ms 종이 상승, 1230~1450ms 페이드 후 원문 표시. 모션 감소는 즉시 전환. 화면 이탈 시 타이머 취소.
- 최초 10개 달성 시 해제, 삭제로 9개 이하가 되어도 재잠금 없음. 후보 0개 빈 상태, 1개 다시 뽑기 숨김. 전체 목록 접근은 랜덤 잠금과 독립.

## [비교 제안] 원문 감상
A. 밝은 라일락 편지지: 낮은 채도, 약한 종이 질감, 짙은 글자, 24px 내부 좌우 여백.
B. 어두운 종이: 기존 다크 퍼플과 가까운 배경, 낮은 대비의 표면 및 경계.
C. 열린 화면: 종이 표면 없이 원문 자체에 집중.
모두 Pretendard 16px/1.75/400/0em, 제목 20px/500. 사용자 원문의 줄바꿈 보존, 제목 없는 경우 생략, 긴 기록은 자연스러운 스크롤. 사용자 서체 설정은 추후 서체별 크기/행간/자간과 예문 미리보기로 구현.

## 코드 구조 및 통합
DrawArtwork(대표 장수, 위치, 선택 인덱스, 모션) / UnlockCopy / DiaryContent(기존) / RediscoverActions. 기존 v0.3 토큰과 버튼, 포커스 규격 사용. 독립 HTML 내 함수 및 CSS로 분리했으며 React 통합은 미진행. 대표 그래픽과 세부 재질은 시안 단계.
