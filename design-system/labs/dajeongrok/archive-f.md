# F안 — 검색 경험 분리형 (v0.14)

## 구현 범위
E안의 기록 정렬, 검색 정규화, 30개 단위 로딩, DiaryRow, 원본 저장 모델을 유지. 기본 목록에서는 AppBar 우측 돋보기만 표시. 기존 A/B/C 검수 시안 유지. 날짜별 목록은 기존 경로 유지. 기록이 없는 전체/월 목록은 검색 버튼 미노출.

## 상태와 복원
- 기본 목록: 월별 그룹, 기본 노출 수와 window scroll 저장.
- 검색 진입: 검색 모달(상단 plain 입력 + 텍스트 필터), 초기에는 원래 목록 유지 및 dim, 배경 inert, body scroll lock. 사용자 클릭 직후 입력 focus, 모바일 키보드 사용.
- 조건 활성: 결과는 날짜 최신순 평면 DiaryRow, 검색 결과 개수, 초기화, 30개씩 더 보기. 조건이 없으면 dim 상태로 복귀.
- 검색어 지우기는 다른 조건 유지. 모든 조건 초기화는 최초 검색 상태. 한글 조합 중에는 입력 표시만 갱신, compositionend 후 검색.
- 닫기/배경 클릭/Escape: 검색 종료, 원본 목록 노출 수/위치 및 돋보기 초점 복원. ESC는 기간 팝업 먼저 닫음. 결과 상세로 이동 시 검색 조건/노출 수/결과 스크롤/행 위치와 원본 목록 상태 보존; 돌아오면 키보드를 강제로 열지 않고 행 초점 복귀. 기록 삭제로 행이 없으면 위치 fallback.
- 월별 진입은 해당 월에 검색 범위 고정, 기간 필터 미노출.

## 기간 선택
공통 PeriodPicker: 기존 menu-bg/border/radius/focus 토큰. 한 화면 3열×4행 월 그리드, 연도 화살표는 기록이 있는 연도 간 이동. 연도 제목으로 12년 단위 연도 그리드, 이전/다음 페이지. 해당 월/연도 선택 즉시 적용. 없는 월·연도 비활성. 전체 기간 및 해당 연도 전체 액션. 열었을 때 현재 선택 연도 또는 최근 기록 연도. 모든 상태에서 팝업 높이 제한, visualViewport 대응, 내부만 스크롤, Escape/바깥 클릭/초점 복귀. 기본 브라우저 picker/select 금지.

## 컴포넌트/토큰
SearchField plain variant: 44px 높이, 20px 아이콘, 16px 글자, 고정 clear 영역; 검색 종료 별도 close. FilterToggle text variant: 44px, 14px 글자, 16px 아이콘, 선택 시 강조색+밑줄, 아이콘 추가 금지. 필터 2열 고정, 긴 텍스트 내부 줄바꿈만 허용. SearchOverlay: 20px gutter, 필터 사이 8px, 결과 간격 16px, dim .45, reduced motion 기본 존중. PeriodPicker 12px inset, 44px target, 8px radius. 새 UI의 내부 용어 사용자에게 노출 금지.
