## 브랜드 / 홈
- [확정] 다정록 / 오늘도 나에게 다정한 한 줄. 고운바탕 워드마크 36px/400/0.05em; 슬로건 Pretendard 16px/400/0.01em; 상단 위치 23%, 간격 16px. 창가 54%, 비둘기 50%, 은방울꽃 50% 포커스. 기본 배경 선택은 보류.
- [확정] 별도 온보딩 없이 실제 홈 진입하는 방향 우선. 첫 방문 및 새 달 최초 감상: 원리/새 작품 안내 문장 순차 등장, 작품명만 중앙에서 상단으로 이동(A), 글자 등장 B(제자리를 찾아), 소멸 B(빛무리). 예시임을 명시하고 실제 기록에는 영향 없음. 평소 재방문은 실제 진행도만큼 글자 모임. 중간에 작성/탭 이동 가능; 모션 감소 지원. 새 달 첫 감상 기본은 기록 0개. 예시는 이전/미공개 월에 재생하지 않음.
- [확정] 홈은 카드 없는 연속 캔버스. 작품명 고운바탕 24px/400/0.015em/1.4. + / 달력↔작품 / 설정, 독립 44px. 작품 제목 달력에서 숨김. 월 전환과 +의 실제 오늘 작성은 독립. 첫 빈 홈: 오늘의 나에게 칭찬 하나 남겨볼까요? 작품 성장 기준은 고유 기록일, 같은 날짜 추가 기록은 높이 불변. 미공개 잠금. 기본 배경 후보 #1E1C27; CTA #282631/#585164/#E9E4F2.

## 작성
- [확정] 선택적 제목 추가 B; 기본 접힘, 본문만으로 저장 가능. 회고 질문 하단 낮은 위계/기본 접힘: 어떤 칭찬을 남길지 고민되나요? 서로 다른 유형 2개, 선택 시 본문 위에 은은하게 표시, 선택/변경/제거해도 본문 불변, 실제 원문에 자동 삽입 금지. 유형은 내부 관리만.
- [유지] 오늘/어제 작성, 선택 날짜 명시, 날짜 경계 지나도 시작한 기록 날짜 유지. 하루 경계 기본/설정은 기존 정책 문서 참고.
## 꺼내보기
- [확정] 잊고 있던 좋은 순간을 우연히 다시 만나는 경험. 10개 개별 기록 최초 달성 시 해제, 일부 삭제로 재잠금하지 않음. 전체 기록 조회 독립. 한 개면 다시 뽑기 숨김, 해제 후 0개면 빈 상태. 원문/줄바꿈 보존. 모든 유효 기록 후보, 시각 쪽지 수와 분리.
- [확정] 잠금 문구: 하루하루 나에게 다정한 말을 모아두어요. / 문득 하나를 꺼내 읽는 날, / 잊고 있던 좋은 순간들이 / 다시 나에게 힘이 되어 줄지도 몰라요. / 10개의 칭찬이 모이면, 하나씩 꺼내볼 수 있어요. 진행 바/9/10 금지. 현재 누적 수 보조 문장 제안.
- [확정] A 둥근 기억병, A1 부드러운 롤, B 나란히 쌓인 구도. 최대 3장 대표 표현. 마개/병/쪽지/배치/모션 독립. 뚜껑 열림 → 선택 → 세로 병목 통과 → 가로 정렬 → 안쪽 면이 드러나게 풀림 → 어두운 종이 B로 전환 → 원문. 4:3 원지, 긴 원문은 세로 확장. V5 풀림 속도/흐름 유지, A1 미술 개선 가능. 기존 방향 비교는 검토 도구만.
- [제안/V6] 유리 전면 반사와 색 투과가 쪽지를 가로지르고, 코르크는 마개 삽입/타원 단면/자연스러운 조직감 강화. 병 외곽/내부 두께/바닥 정교화. 저대비·라인워크 유지. 전체 새 디자인 검토 후 통합.
## 범위
기존 React 앱을 변경하지 않은 실험 스냅샷. 실제 앱과 서버/SDK 연결, 도감/설정 전체 플로우, WCAG/성능/정책 적합성은 별도 작업. 이전 그래픽 연구는 계속 유지.
