# 칭찬일기 Typography v0.3 · 2026-11-21

> **상태: 타이포 위계는 구현 기준안, 글꼴은 시범 후보. 색과 아트 에셋은 미확정.**
>
> 사용자 요청: 완성형 그래픽이 없는 현재 프로토타입에서 폰트·위계부터 정리하고, AI스럽게 무거운 제목/장식적인 세리프/아이콘은 피한다.

## 1. 폰트 후보

- **우선 시안: SUIT Variable** — 한국어 본문·폼·다이얼로그에 필요한 가독성과 가벼운 사용감. [원본/라이선스](https://github.com/sun-typeface/SUIT) · [OFL-1.1](https://github.com/sun-typeface/SUIT/blob/main/LICENSE). 현재 `index.html`에서 공식 공개 CSS를 링크한다.
- **비교 후보: Pretendard Variable** — 이미 사용하던 시스템 느낌의 대안. [원본](https://github.com/orioncactus/pretendard); 라이선스는 SIL OFL. 두 폰트를 혼용하지 않고, 실제 모바일 기기에서 한 가지를 최종 선택한다.
- **Fallback:** Apple SD Gothic Neo / Noto Sans KR / Malgun Gothic / system-ui. 외부 폰트 네트워크 실패가 곧 일기 이용 불가로 이어지지 않아야 한다.
- **미채택:** 장식용 영문 세리프를 이유 없이 한글 헤더와 혼용하는 방식, 과도한 자간 축소, 본문 13px 이하 사용.
- **배포 고려:** 앱인토스 WebView의 CSP·외부 CDN 허용/성능을 점검한 뒤 호스팅 방식을 결정한다. 이 저장소에서 글꼴 바이너리를 직접 배포하지 않는다.

## 2. 단일 타이포 스케일 (CSS 토큰과 동기화)

| 토큰 | 크기/행간 | 굵기 | 쓰이는 곳 |
|---|---|---|---|
| `--type-hero` | 28~32px / 1.3 | 700 | 홈 메인 타이틀 **한 곳** |
| `--type-page` | 26px / 1.3 | 700 | 작성·도감·일기 목록의 화면 제목 |
| `--type-section` | 18px / 1.4 | 600 | 질문/설정의 섹션 제목, 그래픽 제목 |
| `--type-entry-title` | 20px / 1.4 | 600 | 일기 상세의 선택 제목 |
| `--type-body` | 16px / 1.65 | 400 | 실제 일기, 안내 본문, 질문 |
| `--type-control` | 16px / 1.4~1.65 | 600 | 주요 버튼, 핵심 행동 |
| `--type-supporting` | 14px / 1.55 | 400~500 | 설명, 부차적 액션 |
| `--type-meta` | 13px / 1.5 | 400~500 | 날짜·작성일 수·미세 상태 |

**위계 규칙:** 시각적 제목은 한 화면에 하나. 두꺼운 800/900 굵기 사용 안 함. 기본 한국어 본문 자간 0, 제목만 약 -0.025em. 일기 원문은 충분한 행간과 텍스트 리사이즈를 우선한다. `12px` 이하 텍스트는 중요 정보에 사용하지 않는다.

## 3. 화면별 매핑

| 화면 | 최상위 제목 | 읽을 내용 | 한 단계 낮은 텍스트 |
|---|---|---|---|
| 홈 | 월 테마 또는 홈 인사말(중복 시 하나 제거) | 그래픽 | 날짜별 기록 일수, 내 기록 보기 |

| D-02 저장 | 저장 메시지 26 | 변화된 그래픽 | 추가 CTA / 돌아가기 |
| L-01 꺼내보기 | 안내 제목 26 | 안내 16 | 잠금 상태 설명 14 |
| L-02 꺼낸 일기 | 선택 제목 있다면 20 | 원문 16, 행간 1.8 | 원래 날짜 13 |
| C-01 도감 | 도감 제목 26 | 2열 그래픽 | 월/작은 작성일 수 13 |
| S-01 설정 | 상단바 제목 17 | 메뉴 행 16 | 설명·상태 13~14 |

## 4. 접근성 수용 조건

- WCAG 2.2 AA 본문 색 대비 4.5:1, 큰 글자 최소 3:1, 중요 비텍스트 3:1.
- 모바일 화면의 글자 확대 및 **200% 줌에서 기능·내용 유실이 없는지** 확인. 줄바꿈·세로 스크롤을 허용한다. [WCAG 2.2](https://www.w3.org/TR/WCAG22/).
- 터치 44px 이상, reduced-motion 존중. SVG 입자는 장식적 문자인 경우 스크린리더에 일기 본문을 중복 노출하지 않으며, 시각 상태는 별도 `aria-label`로 제공.
- 아트 내부 글자 입자는 **장식적 질감**이라 일반 UI 본문과 같은 크기로 렌더하지 않지만, 아트 진행도/저장 날짜/CTA는 접근 가능한 문자로 별도 전달한다.
