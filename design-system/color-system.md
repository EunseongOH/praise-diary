# 칭찬일기 후보 컬러 및 접근성 — v0.1 (2026-11-21)

## 방향

사용자가 제안한 다섯 색상은 **시각 탐색을 위한 후보**이며 최종 브랜드 컬러가 아니다. 라이트 모드는 흰색 기반, 감성적인 월간 그래픽에는 필요하면 짙은 그린 다크 스테이지를 사용한다. 콘텐츠를 지배하는 그라데이션이나 과장된 아이콘은 배제한다. 부드러운 파스텔의 배경 사용과 **읽을 수 있는 텍스트 대비**를 분리한다.

| 이름 | 사용자 제안 원본 HEX | 용도 | 흰색과의 명도 대비 |
|---|---|---|---|
| Lime | `#B8D68A` | 면 배경·그래픽 일부 | 1.61:1 |
| Leaf | `#61AE72` | 장식·긍정 강조 요소 | 2.69:1 |
| White | `#FFFFFF` | 기본 페이지 바탕 | 1:1 |
| Apricot | `#FAD89E` | 따뜻한 배경 / 월별 포인트 | 1.37:1 |
| Sky | `#A6C5D3` | 겨울 눈꽃 표현 / 보조 그래픽 | 1.82:1 |

위 수치는 sRGB 상대휘도 기반 계산. 원색 자체로 흰색 배경에 작은 글자를 쓸 경우 일반적으로 WCAG 2.2 AA 4.5:1에 미달한다.

## 시맨틱 색상 (초안)

- Page background: `#FFFFFF`
- Primary text: `#273C2F` (화이트 대비 **11.84:1**)
- Muted text: `#465C4C` (화이트 대비 직접 테스트 후 배포 시 고정)
- Action background: `#235C36`, action text `#FFFFFF` (필수 대비 재확인)
- Art panel background: `#162A28` (화이트 대비 **15.04:1**)
- On-dark soft sky: `#A6C5D3` (`#162A28` 대비 **8.27:1**)
- On-dark lime: `#B8D68A` (`#162A28` 대비 **9.33:1**)
- Soft green panel: `#EDF5E7` + dark text `#273C2F`

## 목표 기준

- WCAG 2.2 AA 보통 글자 4.5:1 이상, 큰 글자 3:1 이상.
- 중요한 비텍스트 UI 경계/상태 표시 3:1 이상.
- 글자/그래픽 텍스트의 대비와 상태는 **색만으로 식별하지 않도록** 텍스트 설명 병행.
- 저시력자 배려: 충분한 터치 면적(44px+), 줄바꿈·확대·감소 모션 설정.
- **장식 그래픽**과 **실제 상태 전달 그래픽**은 구분해야 한다. 그래픽을 단순 장식으로 간주해 대비 실패를 무시하지 말고, 필수 진행 상태는 명확한 텍스트로 병기.

## 검증 순서

1. 실제 모바일에서 화이트 기반 홈·작성·도감 구성 확인.
2. 눈꽃/붉은 양을 흰 바탕에서 검증; 형태와 상태가 구분되지 않으면 홈의 아트 영역만 어두운 배경 활용.
3. 손실 대비 색상/폰트/포커스/UI 식별 감사 및 화면 스크린샷 QA.
4. 최종적으로 색상 결정 시 token만 바꾸고 개별 화면에서 헥스 코드 직접 사용하지 않도록 개선.
