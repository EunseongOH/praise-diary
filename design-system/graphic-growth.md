# 그래픽 성장 규칙 v0.3 · 2026-11-21

## 구현 기준 (확정 UX)

- 해당 월 **서로 다른 날짜의 첫 일기**만 아래→위 형상 성장(`writtenDays + 1`).
- 같은 날짜에 추가로 작성한 일기는 **이미 완성된 높이를 유지**하며 글자 입자만 추가.
- 날짜의 마지막 일기를 삭제하면 해당 월의 형상이 아래로 줄어든다. 여러 편 중 일부를 삭제하면 해당 글자만 제거.
- 기존 사용자 문장의 글자만 그래픽 질감에 사용. 새 칭찬이나 단어를 만들어 넣지 않는다.
- 홈/상세/저장/도감은 화면 전체 캔버스에서 통일된 성장 상태를 재현하며, 빈 위쪽은 기본적으로 보이지 않는다.

## 현재 코드가 하는 일 (기술 검증, 미완성 아트)

- `src/graphics/progress.ts`: `writtenDays` → 성장 비율 → 실제 실루엣의 아래쪽부터 채워지는 사각 reveal window.
- `GraphicArtwork.tsx`: 월별 실루엣과 글자를 **하나의 세로 reveal clip**으로 노출. 전체 외곽 ghost를 제거해 과거처럼 완성형 윤곽이 먼저 보이지 않게 함.
- `D-02`: 새 날짜 저장 시 직전 일수의 fill 높이부터 새로운 높이까지 1.1초 애니메이션. 움직임 줄이기/저사양에서는 정적 최종 상태.
- 추가 일기의 경우 글자 밀도만 증가하며 성장 높이는 그대로.
- **12월 목표는 출시 후 확정**: 현재 임시값은 시각적 진행을 검토하는 데만 쓰며, 12월 완성 판정은 하지 않는다.

## 고품질 아트로 확장할 때 필요한 것 (미착수)

1. 테마별 실루엣·형태와 글자 배치 알고리즘 분리 (`themeConfig`, version).
2. 글자 입자를 단순 랜덤 텍스트 배치가 아닌 경로 추종·면적 밀도·다층 깊이로 배치.
3. 새 날짜 저장: 글자 생성 → 상승 → 아래 영역을 채워 결합 → 새 구역 높이 증가. 추가 글은 기존 영역에 스며듦.
4. 초반 1일에서도 눈에 보이는 최소 밀도와 후기 밀도의 균형, 입자 중첩·성능·배터리 테스트.
5. 디바이스 pixel density와 reduced-motion 대응, 30/60fps/정적 fallback.
6. 과거 월 그래픽은 seed + theme asset version으로 동일하게 재생성; 수정·삭제 시 결정적 업데이트.
7. 사용자 일기 원문을 외부 공개 결과물/분석 로그에 자동 노출하지 않음.

**주의:** 현재 도형·입자 품질은 최종 그래픽의 예시가 아니다. 색 역시 임시 후보이다. 이 단계는 "성장 방향 및 데이터 연동"에 대한 동작 증명일 뿐.

## v0.4 추가 — 상징물에 종속된 로컬 모션

눈꽃의 각 큰 줄기와 작은 가지에 고유 로컬 좌표·회전축을 부여하고 글자 기준각을 경로에 맞춰 정렬한다. 미세 회전은 각 가지의 뿌리에서 일어나며, 전체 도형은 랜덤하게 떨지 않는다. 이 기능은 아트 디렉션 프로토타입이며 자세한 미적 기준과 미완성 사항은 `illustration-motion.md`를 참고.
